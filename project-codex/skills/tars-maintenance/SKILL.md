# TARS Maintenance

Read `docs/maintenance-workflow.md`, `docs/lessons-quick.md`, and
`docs/agent-runbook.md`. Inspect current behavior and the Git diff, identify the
root cause, keep scope tight, add a regression check, and run `tars verify`.
Never claim completion while a required check is failing or unexecuted.
