# Service Definition

## One-Line Definition

솔로몬 종합청소업체는 전국의 가정과 사업장 고객이 복잡한 청소와 폐기물을 한 곳에서 상담하고 해결하도록 돕는 회사 홈페이지 서비스다.

## Persona

입주·이사·상업공간·특수청소 또는 폐기물 처리가 필요하지만 업체의 가격, 책임범위, 실제 작업 수준을 비교하기 어려운 개인과 사업장 담당자.

## Core Pain

여러 업체를 따로 찾고 불명확한 견적과 작업 품질을 걱정해야 한다.

## Desired Transformation

Before:

- 어떤 업체와 서비스를 선택해야 하는지 알기 어렵다.

After:

- 작업사례와 비용 기준을 확인하고 한 번의 견적 요청으로 필요한 서비스를 상담한다.

## Core Mechanism

서비스·가격·작업기록을 구조화해 보여주고 사진 기반 무료견적과 전화·카카오 상담으로 연결한다.
