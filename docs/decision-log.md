# Decision Log

## 2026-07-30 — 프로젝트 범위

- 기준 사이트의 공개 서비스 범위를 솔로몬 브랜드로 재구성한다.
- 실시간 웹채팅, 로그인, 마이페이지, 별도 관리자 화면은 초기 범위에서 제외한다.
- 영업지역은 전국이다.
- 후기와 작업사진은 네이버 블로그 및 RSS를 사용한다.

## 2026-07-30 — 디자인

- `신뢰할 수 있는 해결사` 방향을 선택한다.
- 기존 빨강·검정 인지 자산을 현대적인 레드 `#D4362E`와 잉크 `#17191C`로 정리한다.
- 실제 로고 전에는 중앙 `BrandLogo` 컴포넌트의 텍스트 워드마크를 사용한다.

## 2026-07-30 — 기술

- Next.js 호환 vinext 스타터, TypeScript, Node 22를 사용한다.
- 회사·서비스·연락처·브랜드·SEO 데이터를 중앙화한다.
- PC/모바일 반응형, sitemap, robots, canonical, JSON-LD를 출시 필수로 본다.
- 다른 컴퓨터에서는 Git과 `.env.example`, `.nvmrc`, TARS 재진입 프로토콜을 사용한다.

## 2026-08-03 — 패키지 매니저와 개발 포트

- 패키지 매니저는 pnpm 10.15.1로 고정한다.
- 개발 서버 기본 포트는 3002를 사용한다.

## 2026-08-04 — 블로그 RSS 연동

- 네이버 블로그 RSS는 서버에서 읽고 1시간 단위로 재검증한다.
- 외부 RSS 장애나 비정상 응답 시 확인된 대표 게시물을 표시한다.
- RSS 파싱과 서버 통신, 카드 UI를 분리해 이미지 정책 변경의 영향 범위를 제한한다.

## 2026-08-05 — 블로그 이미지 정책

- RSS 본문의 첫 번째 이미지를 작업 카드 대표 이미지로 사용한다.
- `blogthumb.pstatic.net`, `blogpfthumb.phinf.naver.net` 호스트만 허용한다.
- 이미지 URL은 HTTPS 원본 경로로 정규화하고, 유효한 이미지가 없으면 카테고리 플레이스홀더를 유지한다.
