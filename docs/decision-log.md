# Decision Log

## 2026-07-30 — 프로젝트 범위

- 기준 사이트의 공개 서비스 범위를 솔로몬 브랜드로 재구성한다.
- 실시간 웹채팅, 로그인, 마이페이지, 별도 관리자 화면은 초기 범위에서 제외한다.
- 영업지역은 전국이다.
- 후기와 작업사진은 네이버 블로그 및 RSS를 사용한다.

## 2026-07-30 — 디자인

- `신뢰할 수 있는 해결사` 방향을 선택한다.
- 기존 빨강·검정 인지 자산을 현대적인 레드 `#D4362E`와 잉크 `#17191C`로 정리한다.
- 실제 로고 전에는 중앙 `BrandLogo` 컴포넌트의 텍스트 워드마크를 사용한다.

## 2026-07-30 — 기술

- Next.js 호환 vinext 스타터, TypeScript, Node 22를 사용한다.
- 회사·서비스·연락처·브랜드·SEO 데이터를 중앙화한다.
- PC/모바일 반응형, sitemap, robots, canonical, JSON-LD를 출시 필수로 본다.
- 다른 컴퓨터에서는 Git과 `.env.example`, `.nvmrc`, TARS 재진입 프로토콜을 사용한다.

## 2026-08-03 — 패키지 매니저와 개발 포트

- 패키지 매니저는 pnpm 10.15.1로 고정한다.
- 개발 서버 기본 포트는 3002를 사용한다.

## 2026-08-04 — 블로그 RSS 연동

- 네이버 블로그 RSS는 서버에서 읽고 1시간 단위로 재검증한다.
- 외부 RSS 장애나 비정상 응답 시 확인된 대표 게시물을 표시한다.
- RSS 파싱과 서버 통신, 카드 UI를 분리해 이미지 정책 변경의 영향 범위를 제한한다.

## 2026-08-05 — 블로그 이미지 정책

- RSS 본문의 첫 번째 이미지를 작업 카드 대표 이미지로 사용한다.
- `blogthumb.pstatic.net`, `blogpfthumb.phinf.naver.net` 호스트만 허용한다.
- 이미지 URL은 HTTPS 원본 경로로 정규화하고, 유효한 이미지가 없으면 카테고리 플레이스홀더를 유지한다.

## 2026-08-05 — 서비스 상세 콘텐츠

- 서비스별 작업 범위, 현장 확인사항, 제외 범위, 절차, FAQ를 slug 기반 도메인 데이터로 관리한다.
- 상세 페이지는 공통 템플릿을 유지하고 서비스 정책 변경은 도메인 데이터 한 곳에서 처리한다.

## 2026-08-05 — 가격 안내 규칙

- 실제 단가 확정 전에는 금액을 추정하거나 표시하지 않는다.
- 서비스, 규모, 오염도, 접근성, 추가 작업을 평가해 필요한 상담 수준과 비용 영향 요인을 안내한다.

## 2026-08-05 — 지역 페이지

- 전국 영업 범위는 8개 권역 허브로 제공하고 지역명만 바꾼 시·군·구 대량 페이지는 만들지 않는다.
- 권역별 출장 조건과 주요 상담 지역을 고유 콘텐츠로 제공하고 sitemap에 포함한다.

## 2026-08-05 — 견적 서버 검증

- 브라우저 필수값에 의존하지 않고 모든 견적 입력을 서버 도메인 함수에서 검증·정규화한다.
- 저장 adapter 연결 전 검증 endpoint는 개인정보를 보관하지 않는다.

## 2026-08-05 — 견적 사진 저장

- 견적 사진은 공개 URL이 아닌 비공개 R2 key로 저장한다.
- 원본 파일명은 저장 경로에 사용하지 않고 랜덤 UUID와 MIME 기반 확장자를 사용한다.
- 최대 8장, 장당 10MB, JPG·PNG·WebP만 허용하며 저장소 미연결 시 실패를 명시한다.

## 2026-08-05 — 견적 저장

- 정규화된 견적은 D1에 저장하고 사진은 동일한 내부 견적 ID 아래의 비공개 R2 key로 연결한다.
- 고객에게는 내부 UUID 대신 날짜와 임의 문자열로 구성된 접수번호를 반환한다.
- D1 binding이 없으면 실제 접수로 오인되지 않도록 503으로 실패한다.

## 2026-08-05 — 담당자 알림

- 담당자 이메일은 provider interface 뒤의 Resend HTTPS adapter로 발송한다.
- 접수번호를 idempotency key로 사용하고, 알림 실패가 저장된 견적 접수를 롤백하지는 않는다.
- 실제 발송에는 Resend API 키, 검증된 발신주소, 담당자 수신주소가 필요하다.

## 2026-08-05 — 가격·VAT 공개 계약

- 확인되지 않은 서비스 단가는 계속 공개하지 않고 상담 견적제로 명시한다.
- VAT 포함·별도 여부가 확정되기 전에는 견적서에서 반드시 표시한다는 운영 계약만 안내한다.
- 실제 단가와 VAT 정책은 중앙 `pricePolicy`가 소유하며, 대표 확인 후 한 곳에서 전환한다.
